## Правильный ответ

| Действие | Категория MoSCoW |
|---|---|
| Анализ ошибок текущей модели | **Must Have** |
| Попробовать градиентный бустинг | **Should Have** |
| Обучить BERT | **Could Have** |
| Катить текущую модель в прод | **Won't Have** |

В интерфейсе выберите:

```text
Анализ ошибок        → Must Have
Обучить BERT         → Could Have
Катить в прод        → Won't Have
Градиентный бустинг  → Should Have
```

## Почему

Текущая логистическая регрессия имеет `Specificity = 99.6%`, то есть ограничение `> 99.5%` выполнено, но `Recall = 88.7%`, что ниже целевых 90%.

Сначала нужно понять природу ошибок, поэтому **error analysis — Must Have**. После него логично дешёво проверить **градиентный бустинг — Should Have**. BERT дороже, сложнее и не гарантирует улучшение, поэтому **Could Have**. Полноценный автоматический запуск до выполнения acceptance criterion — **Won't Have** для текущего релиза.
