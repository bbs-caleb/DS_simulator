# Page 4 — Lasso regression: контекст, теория и бизнес-применение

## 1. Где мы находимся в уроке

До этой страницы мы прошли три последовательных версии wrapper-отбора признаков:

```text
page_1 — Sequential Forward Selection
page_2 — SFS + парный t-тест
page_3 — SFS + t-тест + поправка Бонферрони
```

Все эти подходы прямо измеряют качество модели для разных подмножеств признаков.

Их преимущество:

```text
мы оцениваем признак через реальную модель и выбранную CV-схему
```

Их главный недостаток:

```text
они могут быть очень дорогими вычислительно
```

На `page_4` появляется другой класс методов — embedded feature selection.

Мы не запускаем отдельный внешний перебор подмножеств. Отбор признаков происходит внутри процесса обучения модели.

Для этого используется:

```python
LassoCV
```

# 2. Главная бизнес-проблема

Представим production-модель с 500 признаками.

Часть признаков:

- полезна;
- дублирует другие признаки;
- является шумом;
- нестабильна;
- требует дорогого расчёта;
- создаёт latency;
- несёт privacy-риски;
- усложняет мониторинг.

Нужно получить более компактную модель.

SFS может решить задачу, но его вычислительная стоимость быстро растёт.

Lasso предлагает более дешёвую альтернативу:

```text
обучить одну линейную модель,
которая одновременно подбирает коэффициенты
и зануляет часть из них
```

---

# 3. Обычная линейная регрессия

Линейная модель предсказывает:

```text
ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ
```

Где:

- `ŷ` — предсказание;
- `β₀` — intercept;
- `βⱼ` — коэффициент признака;
- `xⱼ` — значение признака.

Обычная линейная регрессия выбирает коэффициенты так, чтобы минимизировать сумму квадратов ошибок:

```text
RSS = Σ(yᵢ - ŷᵢ)²
```

Проблема:

```text
обычная регрессия обычно не зануляет
ненужные коэффициенты точно
```

Шумовой признак может получить маленький, но ненулевой коэффициент.

---

# 4. Что такое регуляризация

Регуляризация добавляет к функции потерь штраф за сложность модели.

Идея:

```text
нельзя бесконечно улучшать train fit,
используя большие и нестабильные коэффициенты
```

Модель должна найти компромисс между:

1. качеством подгонки;
2. размером коэффициентов.

---

# 5. L1-регуляризация

Для Lasso оптимизируется выражение вида:

```text
ошибка модели + α × Σ|βⱼ|
```

Вторая часть:

```text
α × Σ|βⱼ|
```

является L1-штрафом.

Где:

- `α` определяет силу регуляризации;
- `|βⱼ|` — абсолютное значение коэффициента.

---

# 6. Почему L1 зануляет коэффициенты

Геометрия L1-ограничения имеет углы на координатных осях.

Оптимальное решение часто попадает именно в такой угол.

Это означает:

```text
один или несколько коэффициентов становятся ровно 0
```

Если:

```python
model.coef_[17] == 0
```

Lasso решила не использовать признак `17`.

Если:

```python
model.coef_[20] != 0
```

признак `20` остаётся в модели.

---

# 7. Почему это feature selection

После обучения можно взять индексы всех ненулевых коэффициентов:

```python
np.where(model.coef_ != 0)[0]
```

И преобразовать их в обычный список:

```python
.tolist()
```

Результат:

```python
selected_features_
```

Например:

```python
[5, 6, 8, 14, 24, 29, 41, 45]
```

---

# 8. Как влияет alpha

## Маленький alpha

Штраф слабый.

Следствия:

- больше ненулевых коэффициентов;
- больше выбранных признаков;
- модель ближе к обычной линейной регрессии;
- выше риск оставить шум.

## Большой alpha

Штраф сильный.

Следствия:

- больше коэффициентов становятся нулевыми;
- меньше выбранных признаков;
- модель проще;
- выше риск отбросить полезный сигнал.

---

# 9. Почему используется LassoCV

Если выбрать `alpha` вручную, легко получить:

- слишком слабую регуляризацию;
- слишком сильную регуляризацию;
- выбор, переобученный на одном holdout.

`LassoCV` перебирает список значений:

```python
alphas=[2, 10]
```

и выбирает alpha через cross-validation.

Упрощённо:

```text
для каждого alpha:
    обучить и оценить Lasso на CV

выбрать alpha с лучшим CV-качеством
```

# 10. Что такое embedded method

Методы отбора признаков обычно делят на три группы.

## Filter methods

Оценивают признаки отдельно от итоговой модели:

- корреляция;
- mutual information;
- chi-square;
- variance threshold.

Плюс:

```text
быстро
```

Минус:

```text
не всегда учитывают совместную работу признаков
```

## Wrapper methods

Многократно обучают модель на разных наборах:

- SFS;
- SBS;
- SFFS;
- SBFS;
- RFE в определённых интерпретациях.

Плюс:

```text
оценивают набор через реальную модель
```

Минус:

```text
дорого
```

## Embedded methods

Отбор встроен в обучение:

- Lasso;
- Elastic Net;
- tree-based importance;
- регуляризованные линейные модели.

Lasso относится именно к embedded methods.

---

# 11. Lasso против SFS

| Критерий | SFS | Lasso |
|---|---|---|
| Тип | Wrapper | Embedded |
| Число обучений | Очень большое | Значительно меньше |
| Модель | Почти любая | Линейная |
| Нелинейные эффекты | Зависит от модели | Не ловит без feature engineering |
| Взаимодействия | Может учитывать выбранная модель | Нужны явно созданные interaction features |
| Отбор | Через CV-метрику | Через нулевые коэффициенты |
| Интерпретируемость | Высокая | Высокая |
| Работа с корреляцией | Жадная и зависимая от пути | Может выбрать один из коррелированных признаков нестабильно |
| Масштабирование | Дорого | Обычно быстрее |

# 12. Почему стандартизация обычно обязательна

L1 штрафует коэффициенты:

```text
|β₁| + |β₂| + ...
```

Если признаки имеют разные масштабы, размеры коэффициентов напрямую несопоставимы.

Пример:

```text
доход измеряется в миллионах
возраст измеряется в годах
доля измеряется от 0 до 1
```

Одинаковый бизнес-эффект может соответствовать очень разным численным коэффициентам.

Тогда Lasso штрафует признаки неравномерно.

Поэтому в реальной задаче обычно нужен pipeline:

```python
StandardScaler()
LassoCV()
```

В текущем синтетическом датасете признаки сформированы из одинакового нормального распределения, поэтому по условию отдельная стандартизация не требуется.

---

# 13. Почему нельзя стандартизировать весь датасет до CV

В реальной задаче неправильно:

```text
fit scaler на всём X
затем cross-validation
```

Так validation folds влияют на mean и std scaler.

Это preprocessing leakage.

Правильнее:

```python
Pipeline(
    [
        ("scaler", StandardScaler()),
        ("lasso", LassoCV(...)),
    ]
)
```

На каждом CV split scaler обучается только на train-части.

# 14. Бизнес-применение: финтех

## Кредитный скоринг

Lasso может помочь сократить:

- транзакционные агрегаты;
- бюро-признаки;
- признаки долговой нагрузки;

Бизнес-ценность:

# 23. Коррелированные признаки

Если два признака почти одинаковы:

```text
x₂ ≈ x₁
```

Lasso может:

- оставить `x₁`;
- оставить `x₂`;
- распределить вклад нестабильно;
- менять выбор при небольшом изменении данных.

Это важно для интерпретации.

Нельзя говорить:

```text
нулевой коэффициент доказывает,
что признак бесполезен в абсолютном смысле
```

Он может быть просто избыточен относительно другого выбранного признака.

---

# 24. Lasso и causal inference

Ненулевой коэффициент не доказывает причинность.

Lasso решает predictive optimization.

Она не доказывает:

```text
изменение x вызовет изменение y
```

Для причинных выводов нужны:

- эксперимент;
- корректный causal design;
- assumptions;
- контроль confounding;
- causal estimators.

---

# 25. Lasso и leakage

Lasso не защищает от утечки.

Если признак содержит информацию из будущего или прямо кодирует таргет:

- коэффициент будет ненулевым;
- CV при неправильном split покажет высокое качество;
- selector уверенно выберет плохой production-feature.

Feature selection не заменяет audit происхождения данных.

# 26. API задания

Конструктор:

```python
selector = LassoSelector(
    cv=cv,
    alphas=[2, 10],
    random_state=42,
)
```

Он сохраняет:

```python
self.cv
self.alphas
self.random_state
```

До fit:

```python
self.n_features_ = None
self.selected_features_ = None
```

После fit:

```python
self.n_features_ = X.shape[1]
self.selected_features_ = [...]
```

Свойство:

```python
selector.n_selected_features_
```

возвращает длину выбранного списка.

---

# 27. Полный алгоритм

```text
1. Сохранить число входных признаков.

2. Создать LassoCV:
   - cv = переданная схема;
   - alphas = переданный список;
   - random_state = переданное значение.

3. Обучить LassoCV на X и y.

4. Получить model.coef_.

5. Найти индексы, где коэффициент не равен 0.

6. Сохранить индексы в selected_features_.

7. transform возвращает X только с этими колонками.
```

# 28. Итоговое мышление специалиста

Lasso не является «магической кнопкой удаления плохих признаков».

Сильный специалист проверяет:

- корректность CV;
- масштабирование;
- стабильность выбранных признаков;
- корреляции;
- data leakage;
- стоимость feature pipelines;
- бизнес-метрику;
- performance на holdout;
- drift;
- fairness;
- интерпретацию.
