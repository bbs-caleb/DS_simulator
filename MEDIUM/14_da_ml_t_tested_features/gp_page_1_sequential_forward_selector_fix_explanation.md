# Исправление `SequentialForwardSelector`

## Почему предыдущая версия получила 20 баллов

API класса и стиль кода были корректными, поэтому прошли проверки:

- `xtest_sequential_forward_selector_api`;
- `test_pylint`.

Но основная логика SFS была реализована не полностью. Предыдущая версия всегда выполняла ровно `max_features` итераций и добавляла очередной признак даже тогда, когда качество модели уже переставало улучшаться.

В условии `max_features` означает **максимально допустимое**, а не обязательно итоговое количество признаков.

Правильное правило:

1. найти лучший кандидат среди ещё не выбранных признаков;
2. сравнить его средний CV-score с качеством текущего набора;
3. добавить признак только при строгом улучшении;
4. если улучшения нет, остановить алгоритм раньше `max_features`.

## Что происходило на `random_state = 69`

После восьми выбранных признаков правильный набор был:

```python
[8, 9, 10, 17, 20, 26, 44, 46]
```

Средний `R2` для следующего лучшего кандидата оказался ниже текущего результата. Однако старая версия всё равно добавила признаки `32` и `31`, поэтому вернула десять признаков:

```python
[8, 9, 10, 17, 20, 26, 31, 32, 44, 46]
```

Именно поэтому тест сообщил, что ожидал восемь признаков, но получил десять.

## Ключевое исправление

Добавляется переменная, которая хранит качество текущего выбранного набора:

```python
current_score = float("-inf")
```

После поиска лучшего кандидата выполняется проверка:

```python
if self.selected_features_ and best_score <= current_score:
    break
```

Если новый признак не повышает среднее значение `R2`, алгоритм прекращает работу.

После успешного добавления признака новое качество сохраняется:

```python
current_score = best_score
```

## Почему используется строгое `>`

Признак должен действительно улучшать метрику. Если новый результат равен текущему, полезность признака не доказана, но модель становится сложнее. Поэтому при условии

```python
best_score <= current_score
```

отбор останавливается.

## Локальная проверка ошибки из теста

Исправленный файл проверен на тех же параметрах, которые видны в сообщении проверяющей системы:

```text

actual   = [8, 9, 10, 17, 20, 26, 44, 46]
number of selected features = 8

```

Проверка прошла успешно.
